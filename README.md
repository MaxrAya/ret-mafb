# Mafia — Telegram-бот «Мафия»

Игровой бот для партий по мафии в Telegram-группах: голосование, ночная фаза, рейтинг, статистика, достижения и турниры.

## Возможности

- Партии в группах от 4 до 20 игроков, роли раздаются автоматически.
- Ночная фаза с личными сообщениями: мафия выбирает жертву, шериф проверяет, доктор лечит (один раз за партию, может вылечить себя).
- Живое голосование: сообщение-таймер обновляется каждые 5 секунд, баннеры фаз — каждые 15 секунд.
- Мьют мёртвых до конца партии, авто-удаление их сообщений, тишина в группе ночью.
- Дополнительные роли (включаются в настройках лобби): дон, сильный мафиози, шериф, доктор, клоун, охотник.
- Пресеты настроек лобби: ⚡ Быстрая, 🎲 Классика, 🐢 Длинная.
- Реванш: кнопка «🔁 Ещё партия» под итогами — тот же состав сразу новой партией.
- Рейтинг ELO (глобальный и по чату), статистика побед/поражений, таблицы лидеров.
- Топы за неделю и за месяц (по изменению рейтинга).
- Достижения, история партий, профиль игрока.
- Турниры: регистрация, старт, таблица результатов с рейтингом.
- Уведомления в ЛС: `/subscribe` — бот напишет, когда в группе начнут собирать партию.
- Фильтр мата: плохие слова удаляются, автор получает предупреждение.
- Гифки-заставки фаз: `/setgif night|day|vote|end|start`.
- Роли и правила по командам, настройки — кнопками прямо в чате.

## Стек

Python 3.12 · aiogram 3.31 · SQLAlchemy 2 (async) · aiosqlite · pydantic-settings · pytest · ruff

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows; Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
copy .env.example .env        # Windows; Linux/macOS: cp .env.example .env
```

Открой `.env`, вставь токен от [@BotFather](https://t.me/BotFather) в `BOT_TOKEN`. При желании укажи `ADMIN_IDS` (id админов через запятую).

```bash
python bot.py
```

Бота нужно добавить в группу и выдать права на удаление сообщений и ограничение участников (мьют).

## Основные команды

| Команда | Назначение |
|---|---|
| `/mafia` | создать лобби (настройки кнопками, «Старт») |
| `/game` | состояние текущей партии |
| `/skip` | пропустить фазу (для хоста) |
| `/profile` | статистика игрока |
| `/top` | рейтинг (глобальный / по чату) |
| `/achievements` | достижения |
| `/matches` | история партий |
| `/tournament` | турниры |
| `/subscribe` / `/unsubscribe` | ЛС-уведомления о сборах партий |
| `/setgif night\|day\|vote\|end\|start` | своя гифка фазы (админ чата) |
| `/forcend [town\|mafia]` | завершить партию с подсчётом рейтинга (админ) |
| `/admin_skip` | пропустить фазу (админ, не только хост) |
| `/admin_stop` | остановить партию без рейтинга (админ) |
| `/admin_stats` | статистика бота (владелец) |
| `/rules`, `/help` | правила и помощь |

## Правила партии (кратко)

- Победа мафии — когда живых мафиози не меньше половины остальных; победа города — когда мафия вся мертва.
- Казнь по голосованию: нужно большинство `живых/2 + 1`; ничья топов — никого не казнят.
- Клоун побеждает, если его казнили (и город не проиграл иначе).
- Охотник при смерти имеет право выстрелить (в том числе цепочкой).
